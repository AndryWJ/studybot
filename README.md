# StudyBot

Telegram-бот, який допомагає школярам і студентам вчитися без авралів: веде розклад, нагадує про дедлайни, рахує, скільки годин потрібно кожному предмету перед іспитом, і розкладає підготовку по вільних днях. Уміє робити конспекти й тести, показує прогрес і середній бал.

Усе працює на безкоштовних тарифах: сервер, база й щохвилинні нагадування живуть на Cloudflare Workers, а штучний інтелект бере Groq. Платити не потрібно, банківська картка для цих тарифів зазвичай не потрібна.

## Що вміє бот

| Задача | Що робить бот |
|---|---|
| Персональний розклад | Записує уроки, пари й самопідготовку; ШІ може скласти розклад за описом тижня |
| Нагадування про дедлайни | Розуміє "реферат з біології в четвер о 10", нагадує за добу, за 2 години і в момент дедлайну |
| Визначення пріоритетів | Упорядковує дедлайни за терміном, важливістю і складністю (🔴 🟡 🟢) |
| Розрахунок часу | Рахує, скільки годин дати кожному предмету за складністю й рівнем підготовки |
| Розподіл навантаження | Розкладає заняття й кроки завдань по вільних днях, не перевантажуючи |
| Оптимізація розкладу | Встигає до кожного іспиту за обмеженого часу; що не влазить, передає іншим предметам |
| Розбивка завдань | Ділить велике завдання на кроки з датами до дедлайну |
| Конспекти й тести | Короткий конспект і вікторина з підрахунком балів за текстом чи темою; за фото сторінок, якщо підключено ШІ, що розпізнає зображення (наприклад, Gemini) |
| Підготовка до НМТ | План з урахуванням формату НМТ і поради, що вчити |
| Оцінювання прогресу | Відсоток виконаних кроків і занять, таймер навчання |
| Аналіз оцінок | Середній бал і скільки треба отримати для бажаної підсумкової |
| Графіки | Витрачений час і виконані завдання: у чаті та на окремій сторінці |

Приклад: 12 годин на три предмети. Математика (складність 5, рівень 2, іспит через 10 днів) отримує 7,5 год, фізика (3 і 3, через 14 днів) 3 год, англійська (2 і 4, через 20 днів) 1,5 год, і всі заняття стоять до відповідних іспитів. Як саме це рахується, описано в [docs/how-it-works.md](docs/how-it-works.md).

## Як запустити

Потрібні Node.js 22.12 або новіший, Git і три безкоштовні акаунти: Telegram, Cloudflare, Groq. Повна інструкція з поясненням кожного кроку: [docs/launch.md](docs/launch.md).

```bash
git clone https://github.com/AndryWJ/studybot.git
cd studybot
npm install
npx wrangler login
npx wrangler d1 create studybot --location eeur --binding DB   # сам впише id бази в wrangler.jsonc
npm run db:migrate                                             # на запитання відповісти y
npm run deploy                                                 # перший раз попросить вибрати піддомен workers.dev
npx wrangler secret put TELEGRAM_BOT_TOKEN                     # токен від @BotFather
npx wrangler secret put WEBHOOK_SECRET                         # вигаданий довгий рядок, див. docs/launch.md, крок 8
npx wrangler secret put GROQ_API_KEY                           # ключ з console.groq.com
```

Наостанок відкрийте в браузері `https://studybot.<ваш-піддомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>`, підставивши піддомен, вибраний під час `deploy`, і свій секрет: сторінка підключить бота до Telegram і покаже, чи все готово.

## Куди заходити

| Що | Де |
|---|---|
| Сам бот | У Telegram за іменем, яке ви дали в @BotFather, команда `/start` |
| Перевірка, що все налаштовано | `https://studybot.<ваш-піддомен>.workers.dev/setup?secret=...` |
| Логи бота | `npm run logs` або панель Cloudflare, розділ Workers, воркер studybot |
| Дані | Панель Cloudflare, розділ D1, база studybot |
| Статистика для власника | Команда `/stats` у боті (якщо ваш Telegram id записано в `ADMIN_ID`) |

## Перевірка

`npm test` запускає 650+ автоматичних тестів у локальному середовищі Cloudflare, `npm run e2e` проганяє бота наскрізь проти підставних Telegram і ШІ.
